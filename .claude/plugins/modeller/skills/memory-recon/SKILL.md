Memory is optional generated recall, not authority.

Use order:

1. repository maps and registry for ownership;
2. Git/source files for current truth;
3. modeller-memory graph or recall for search acceleration;
4. fallback text search when memory is unavailable or stale.

Record whether memory was used, unavailable, or intentionally skipped.
