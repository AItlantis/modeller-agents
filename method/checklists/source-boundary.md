# Source Boundary Checklist

- [ ] Target source-of-truth repository is identified.
- [ ] Write paths are inside the owning repository.
- [ ] Generated artifacts are not edited as source.
- [ ] Durable knowledge changes go through review.
- [ ] Pipeline contracts remain in `modeller-pipelines`.
- [ ] Backend implementation remains in backend repositories.
- [ ] Product behavior remains in Testudo.
- [ ] Repository-local agents remain in their source repositories.
- [ ] Memory is treated as generated recall, not authority.
